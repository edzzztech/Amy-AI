Local-first desktop assistant

Your computer, talked to.

Amy is a voice assistant that runs on your own machine. She hears you across the room, looks at whatever is on your screen, drives your apps for you, and models real CAD parts — with the language models running locally through Ollama, so nothing is shipped off to an API.

Capabilities

Not a chatbot in a window

Amy has hands, eyes and ears on the machine she runs on. Every subsystem below is part of the same process — one wake word reaches all of them.

Full-duplex voice

She listens while she speaks. Interrupt her mid-sentence and she stops — barge-in is voice-activated, with a clap as a backup wake signal.

Screen awareness

A vision model reads your actual display on an interval. Ask what's on screen, what an error means, or what that dialog is asking for.

Computer control

An agent that finds and drives real applications through UI automation — opening, clicking, typing. Risky steps wait for your approval first.

Real CAD, not meshes

CadQuery builds exact B-rep solids — hinged assemblies, tolerances, STEP export — then a visual check confirms the part came out as described.

Desk camera & gestures

Point the webcam at something and ask what it is. Hand gestures map to actions — open palm pauses media, fist mutes, peace skips the track.

Proactive engine

She thinks on a timer, watches folders for new files, and raises things worth raising — rate-limited, and silent during quiet hours.

Memory that persists

Transcripts, a knowledge base and learned skills live on disk in amy_data, watched for changes and recalled in later conversations.

Model routing

Separate local models for fast replies, reasoning, code, CAD and vision. Auto-select picks the right one per request instead of one model for everything.

Everything stays home

Inference runs against localhost. Mail, messaging and smart-home integrations are opt-in, and credentials live only in your own config file.

Architecture

One pass, wake word to voice

What happens between you saying “Amy” and hearing an answer back.

Always listening, cheaplyVoice activity detection gates the expensive stages, so the transcriber only runs on real speech.
Grammar before guessingConfident phrase matches execute directly; borderline ones get a clarifying question instead of a wrong action.
Approval gatesAnything classified as risky pauses for a yes, with a timeout that defaults to declining.
Spoken replies stay shortThe full answer lands on the on-screen card; the voice gets the summary.
Setup

Running in four steps

Windows, Python 3.10 or newer, and a machine with enough headroom to host a local model.

Clone and install

CadQuery and OpenCV are heavy, but they're imported lazily — nothing loads until you ask for CAD or the camera.

git clone https://github.com/edzzztech/Amy-AI.git
cd Amy-AI
pip install -r requirements.txt

Pull the local models

Install Ollama, then pull a chat model, a vision model and an embedding model. Amy can start the Ollama server herself on launch.

ollama pull llama3.2          # conversation + reasoning
ollama pull llava             # screen and camera vision
ollama pull nomic-embed-text  # memory search

Fill in your config

Open amy_config.json and replace the placeholders. Everything is optional except the Ollama block — skip any integration you don't want and that feature simply stays quiet.

"assistant": {
  "wake_word": "amy",
  "user_title": "Sir",
  "default_city": "London",
  "neural_voice": "en-GB-SoniaNeural"
}

Say hello

She greets you on launch, then waits for the wake word. Say “Amy, what can you do?” to hear the current skill list.

python amy.py
Configuration

Worth knowing about

amy_config.json holds every key and tunable — nothing is hard-coded in the source. These are the settings most worth changing first.

SettingDefaultWhat it does
assistant.wake_wordamyWhat she answers to. Pick something that doesn't collide with your normal speech.
assistant.neural_voiceen-GB-SoniaNeuralAny Microsoft Edge neural voice. Free, no key, and far better than system TTS.
assistant.barge_invoiceHow to interrupt her mid-reply. voice cuts her off as soon as you start talking.
assistant.automation_approvalriskyWhen to ask before acting. risky gates destructive steps only; all gates everything.
assistant.allow_shell_commandsfalseOff by default, deliberately. Turn it on only if you want her running shell commands.
ollama.auto_selecttrueRoutes each request to the fast, reasoning, code, CAD or vision model automatically.
ollama.auto_starttrueStarts the Ollama server on launch if it isn't already running.
proactive.levelnormalHow often she speaks up unprompted, bounded by quiet_hours and max_per_hour.
camera.start_on_launchfalseThe webcam stays off until you ask for it. Gestures need it running.
ui.themearcWindow theme, plus which controls appear in the bottom bar.
